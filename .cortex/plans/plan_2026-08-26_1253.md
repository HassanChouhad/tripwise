1. **Create a `ThemeContext`** (`app/context/ThemeContext.js`)
   - Client component with React context
   - Stores theme in `localStorage` and applies `data-theme="light"` or `data-theme="dark"` on `<html>`
   - Respects system preference on first visit via `prefers-color-scheme`

2. **Add light theme CSS variables** to `globals.css`
   - Add `[data-theme="light"]` block with light-appropriate colors (white/gray backgrounds, dark text, adjusted borders/shadows/gradients)

3. **Wrap `layout.js`** with the new `ThemeProvider`
